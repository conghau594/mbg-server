Detailed Description

template<typename T>
class mbg::iFiniteArray< T >

Interface for a finite array container.

This class provides an interface for a finite array container that supports basic operations such as adding and removing elements, accessing elements by index, checking if the array is full, collapsing the array, and moving elements to another array.

Template Parameters
TThe type of elements stored in the array.
